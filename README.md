# Flowrate Plumbing & Heating Solutions

Homepage for Flowrate Plumbing & Heating Solutions, a Gas Safe registered heating engineer and plumber in Telford, Shropshire (07982 303749).

A single static page: `index.html` plus the images in `assets/`. No build step, so it can be hosted as-is on GitHub Pages, Netlify or Vercel.

Customers get in touch by phone or WhatsApp; every call button is tap-to-call on mobile.
